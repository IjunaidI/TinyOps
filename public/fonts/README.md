# Archived TinyOps pixel fonts

These unmodified files are retained from the earlier pixel typography theme. The current interface and city signs use native system sans-serif fonts and do not load these files.

Retrieved from the official Google Fonts CDN on October 3, 2026. These are the CDN's unmodified Latin WOFF2 subsets, served with no external runtime request. The original copyright notices and full licenses were retrieved from the [Pixelify Sans](https://github.com/google/fonts/tree/main/ofl/pixelifysans) and [Silkscreen](https://github.com/google/fonts/tree/main/ofl/silkscreen) directories in the official Google Fonts repository and accompany the files. The former theme used Pixelify Sans for interface text and Silkscreen for short display labels.
